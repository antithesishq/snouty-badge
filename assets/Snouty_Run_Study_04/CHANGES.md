# Snouty Run Study 04 – Change summary

Requested tweak: make the rear hem a bit more compact, and move the tail forward if possible without causing collisions with the back foot during stride.

Implemented changes:

- Moved the visible tail one more native pixel forward.
- Removed the prior downward tail bias so the tail stays a touch higher, preserving clearance from the rear foot in stride.
- Trimmed the rear sweatshirt hem and back silhouette by about one more native pixel so the design feels less back-heavy.
- Preserved the approved 16-frame timing, gait, bounce, planted-foot spacing, secondary motion, palette, and overall Genesis-style rendering.

Net effect:

- The rear body silhouette is more compact.
- The tail reads as attaching under the shirt closer to the pelvis.
- The shirt no longer needs as much rear overhang to explain the silhouette.
