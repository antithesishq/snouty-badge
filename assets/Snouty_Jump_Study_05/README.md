# Snouty Jump Study 05

This pack updates **only the chest logo element** in the jump frames.
The sprite poses, silhouette, timing assets, and general artwork remain unchanged.

## What changed
- Replaced the previous pixel logo mark on Snouty's shirt.
- Matched it to the user-provided Antithesis logo and the user-provided revised run sprite.
- Applied as a deterministic pixel edit rather than regenerating the character.

## Included files
- `frames/` — 12 individual 96x96 transparent PNG frames
- `snouty_jump_strip.png` — 12-frame horizontal strip
- `snouty_jump_sheet.png` — 6x2 sprite sheet
- `snouty_jump_contact_sheet.png` — enlarged review sheet
- `snouty_jump_review.gif` — quick transparent review animation
- `reference_logo_and_run_sprite.png` — the two reference images used for the logo correction
- `snouty_jump.json` — metadata about frame placement and correction
