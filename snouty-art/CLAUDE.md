# snouty-art

Pixel art pipeline for Snouty (Antithesis mascot) badge carts. Read PLAN.md.

- Never hand-edit files under `out/`; they are regenerated by
  `python3 tools/build.py` (all styles) or `--style NAME`. Edit the style's
  `anim/*.py` override, the shared `snoutyart/anim/*.py`, or the style's rig.
- One directory per visual style under `styles/`. Colours are role names on
  `rig.pal` (FUR, SHIRT, NET, OUTLINE ...), never hex literals, so shared
  animations render in every style. Max 15 colours per style plus transparency.
- Changing one style must not change another style's `out/`; check with
  `git status` after a full build.
- Cells are 96x96, origin (48,88), character faces right, ground baseline y=88.
- Review art by rendering the contact sheet or preview GIF and looking at it
  (the Read tool shows PNGs); do not judge frames from pixel diffs alone.
- Keep frame counts and semantics from PLAN.md so `../snouty-badge` can swap
  packs without cart code changes beyond the feet-row tables.
