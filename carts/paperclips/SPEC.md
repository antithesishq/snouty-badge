# Universal Paperclips for the SYCL badge: design

A faithful port of *Universal Paperclips* by Frank Lantz and Bennett Foddy
(2017) to the SYCL Badge V2, ported with the authors' permission (Adrian
obtained it, 2026-10-04). The source is the public mirror
<https://github.com/jgmize/paperclips> at d1e9177 (2018-11-16), copied
unchanged into `reference/`: `main.js`, `projects.js`, `combat.js`,
`globals.js`, `index2.html`, `interface.css`, `title.png`. That mirror
removed Google Analytics and uncommented the cheat buttons. Nothing else.

Directory `carts/paperclips`, binary `paperclips`, menu title
"Universal Paperclips".

## 1. What "faithful" means

- **The rules are the original's, number for number.** Every variable,
  formula, cost curve, random draw, threshold, message text and project
  (all 97 in `projects.js`) is ported. Where the JS has bugs or oddities
  (the "AutoClippper" typo in a message, the `margin` float drift from
  repeated `+ .01`, integer floors, `toFixed` rounding), we keep them. The
  port is checked against the original JS running headless (PLAN.md,
  the oracle).
- **The timing is the original's.** The JS drives the game from
  `setInterval` timers: 10 ms (the main loop), 100 ms (sales, wire price,
  the strategy picker read, the stock display), 1000 ms (stock buying),
  2500 ms (stock selling and prices), 16 ms (combat) and `setTimeout`
  chains (tournament rounds and so on). The port keeps a virtual
  millisecond clock and fires the same timers at the same virtual times,
  in the same order (section 5). The badge advances that clock by real
  frame time, so one hour on the badge is one hour of the original.
- **The screen is not the original's.** The browser page is a 1000 px
  wide panel layout. The badge has 160 x 128 pixels and eight buttons.
  The UI is a set of pages that hold the same panels, controls and
  numbers (section 3). Look: the original's, black text on white, plain
  and spare.
- **Left out:** the Threnody audio (the badge speaker is off for every
  cart), the original's three save slots, Google Analytics (already
  gone), the browser's "Are you sure" reset dialog. On the organizers' OS
  a game lasts while the cart runs (no cart save storage). On the patched
  OS with cart saves (branch `saves/m1`) the cart keeps one saved game
  with autosave, CONTINUE on the title and a save on "Exit cart"
  (docs/RUNNING.md section 9).

## 2. Hardware fit

- **Numbers are `f64`, as in JS.** The Cortex-M33 FPU is single precision,
  so `f64` is soft-float. That is fine: the sim does at most a few
  thousand f64 operations per 10 ms tick, and only `ticks_per_frame`
  (1-2) ticks run per frame. `zig build check-float` does not include
  this cart (by design, it needs soft f64). Budget below.
- **RAM.** Game state is a few KB; project and message text a few tens of
  KB of `.rodata`; the title picture as 4-bit palette (10 KB). Target:
  `.text + .data + .bss` under 200 KB of the 274 KB RAM cart window.
- **Frame budget.** `update()` under 10 ms worst case on badge-bench
  (calibrated, `busy ms`), mean under 5 ms, at 60 fps. The sim's late game
  (swarm, probes, combat, `Math.pow` in loops) is the risk; measure it.
- **RAM cart only** (XIP is gone from the firmware). No neopixels, no
  sound, never bind the joystick click, react to neither Start nor Select
  while both are held (the OS settings chord).

## 3. Screen and controls

Text uses a 5x7 font in a 6x8 cell (26 columns x 16 rows) generated by a
host script into a committed `.zig` table, with the OS 8x8 font only for
the title. Layout, top to bottom:

```
 Paperclips: 1,234,567          header: total clips, always (big on stage 1)
 $12.34  Wire 830  Ops 120/3k   status: the 3-4 numbers that matter now
 < BUSINESS >            2/6 !  page tab: name, index, "!" on pages with news
 > Make Paperclip               rows: one control or readout per row,
   Price per Clip $.25   A+ B-  the cursor on the selected row
   Public Demand 32%
   Marketing Lvl 2   $200.00
   ...
 ------------------------------
 > AutoClippper performance...  ticker: the newest console message
```

Controls (the same on every page):

- **Up/Down** move the cursor over the page's rows (pages scroll).
- **Left/Right** switch pages.
- **A** presses the selected row (a button: buy, make, toggle, run). On a
  value row (price, probe trust, swarm slider, investment risk, strategy
  pick) A raises / steps forward. Holding A repeats after 0.4 s at 8 per
  second on buy rows. "Make Paperclip" never repeats: clicks are clicks.
- **B** lowers / steps back on value rows; elsewhere nothing.
- **Start** opens the full message log (the original's console) and
  closes it.
- **Select** jumps to the page with news (the "!" one), if any.

A disabled button (the original's `disabled`: can't afford, not yet) is
drawn grey and A does nothing. A row appears when the original's element
appears (the JS `style.display` toggles), so the game unfolds as it does
in the browser.

Pages, each holding the original panels named:

| page | panels | appears |
|---|---|---|
| BUSINESS | Make Paperclip, Business (funds, rev/s, unsold, price, demand, marketing) | start; Business goes away in stage 2 |
| MANUFACTURING | clips/s, wire, WireBuyer, AutoClippers, MegaClippers | start |
| COMPUTING | Trust, processors, memory, operations, creativity; Quantum Computing (chips drawn as squares of their brightness, Compute) | compFlag / qFlag |
| PROJECTS | the active projects: title + price, the selected one's description below; A buys | projectsFlag |
| INVESTMENTS | risk, deposit, withdraw, cash/stocks/total, 5 stock lines, engine upgrade | investmentEngineFlag |
| STRATEGY | strat pick, Run, New Tournament, AutoTourney, the 2x2 payoff grid, round results, yomi | strategyEngineFlag |
| FACTORIES | Manufacturing (stage 2): factories, unused clips, disassemble | factoryFlag |
| WIRE | Wire Production: matter, harvesters, wire drones (+1/+10/+100/+1k), disassemble | wireProductionFlag |
| POWER | performance, consumption, production, solar farms, batteries, storage | powerDiv |
| SWARM | drones, status, gifts, feed/teach/entertain/clad/synch, work/think slider | swarm divs |
| SPACE | % explored, launch probe, launched/descendants/lost/drifters | spaceFlag |
| PROBE | Von Neumann Probe Design: trust allocation rows, increase trust / max trust, honor | probeDesignDiv |
| COMBAT | the battle drawn in a box (ships, drifters), battle number, result, honor | battleCanvasDiv |
| CHEATS | the mirror's cheat buttons; hidden until the code below | the code |

The page order follows the original's columns; stage-specific pages
appear and disappear with their panels.

**Title.** `title.png` (the paperclip box) scaled to the screen, "Press A",
the credit line ("by Frank Lantz & Bennett Foddy"), and "Universe: n /
Sim Level: m" after a prestige. The code Up Up Down Down Left Right Left
Right B A on the title unlocks the CHEATS page for the session.

**Ending.** The disassembly sequence plays as in the original (the JS's
`dismantle` steps and `endTimer` messages), pages vanish as their panels
do, down to the last panel and the final clip count. Then the original's
closing choice; A starts the next universe (prestige kept for the
session).

## 4. Code layout

- `cart/src/game/` is the port of the JS and knows nothing about the
  screen (host-testable, no `cart-api`): `game.zig` (the `Game` struct,
  `init`, `advance_ms`, `act`, `enabled`), the JS globals as fields in
  snake_case (`unsoldClips` -> `unsold_clips`), `projects.zig` (the 97
  projects: text, trigger, cost, effect), `combat.zig`, `stocks.zig`,
  `strategy.zig`, `rng.zig`, `fmt.zig` (`numberCruncher`, `timeCruncher`,
  `toLocaleString`, `toFixed`, exactly as JS prints them), `timers.zig`
  (the virtual clock).
- `cart/src/ui/` draws and reads input: `font.zig` + `gen/`, `pages.zig`,
  `layout.zig`, `widgets.zig`, `title.zig`, `combat_view.zig`,
  `numfmt.zig` (compact screen formats).
- `cart/src/main.zig`: `start`/`update`, frame-time to virtual-clock,
  the wasm shims, debug exports.
- `tools/`: `js_oracle.mjs` (runs `reference/*.js` headless in Node with a
  stub DOM and the same RNG, clock and action script), `oracle_runner.zig`
  (the same script through `game/`), `compare.mjs`, `check.sh` (the gate),
  `gen_font.py`, `gen_title.py`, input scripts.

## 5. Determinism contract (shared by the port and the oracle)

- **RNG.** `Math.random()` is replaced, in the port and in the oracle, by
  xorshift64*: `x ^= x >> 12; x ^= x << 25; x ^= x >> 27; r = x *
  0x2545F4914F6CDD1D (mod 2^64)`, result `(r >> 11) * 2^-53` as f64; seed
  `x = seed` (nonzero). The port calls it exactly where and as often as the
  JS calls `Math.random()`, including in display-side code that draws.
- **Clock.** A virtual clock in integer milliseconds starting at 0. Each
  timer has a period (setInterval) or due time (setTimeout); at each ms,
  due timers fire in order of registration (`index2.html` loads
  `combat.js`, `globals.js`, `projects.js`, `main.js`, in that order; then
  file order; timers registered later fire after earlier ones due the same
  ms). The badge advances the clock by 16 or 17 ms per frame (60 fps:
  17, 17, 16 repeating) and fires everything due.
- **Actions.** Button presses are `Action` values applied between clock
  steps, at a given virtual ms.
