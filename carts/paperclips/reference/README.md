# Original source (reference only)

*Universal Paperclips* by Frank Lantz and Bennett Foddy (2017),
<http://www.decisionproblem.com/paperclips/>, ported to the badge with the
authors' permission. These files are copied unchanged from the public mirror
<https://github.com/jgmize/paperclips> (`docs/`, commit d1e9177, 2018-11-16),
which removed Google Analytics and uncommented the cheat buttons.

The cart does not build from these files. They are the specification of the
port and the input of the oracle (`tools/js_oracle.mjs`), which runs them
headless and compares them with the Zig port.
