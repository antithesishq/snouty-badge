# Snouty vs. the Bugs

A bullet-hell shooter cart for the SYCL Badge V2. Snouty, the Antithesis
mascot, zaps software bugs from a tiny spaceship. Plays itself until you
press a button.

- `SPEC.md`: game design, architecture, milestones.
- `ASSETS.md`: brief for the pixel-art agent.
- `docs/RUNNING.md`: build, simulate, flash.

Companion cart: [snouty-run](../snouty-run), in the same repository.
