# Snouty - Jump Study 02

A rebuilt jump suite for Snouty, designed to be more readable and more dramatic than the previous pass.


## Preview timing revision

This package updates the review GIFs so the standing jump clearly begins from the true standing pose and both previews play substantially slower for readability.


## Art correction

This revision corrects the rear/far eye coloration in the standing and jumping frames so both eyes remain clearly readable and white, matching the approved run cycle. No pose regeneration was used; the fix was applied as a deterministic pixel edit and the derived sprite sheets / GIF previews were rebuilt from the corrected frames.
