# Snouty Zero (cart notes)

F-Zero style Mode 7 hover racer on a planet-sized AI datacenter. `SPEC.md`
is the design, `PLAN.md` the milestone contract and status; read both
before changing anything. The repository-wide rules are in the root
`CLAUDE.md`.

## Modules (`cart/src/`)

- `main.zig`: `start`, `update`, the state machine, wasm shims, debug exports.
- `fixed.zig`: Q16.16, turn angles (`u16`, 65536 per revolution, 0 = +x,
  16384 = +y), sin/cos from the committed `gen/sin.zig`, xorshift rng.
- `tuning.zig`: every constant (camera, physics, thermal, rewind). Change
  numbers here, not in the modules.
- `camera.zig`, `render.zig` (floor tables + inner loop, horizon strip,
  fog banks), `track.zig` (embedded league art and track data accessors).
- M1+: `world.zig`, `sim.zig`, `history.zig`, `hud.zig`, `ai.zig`, `sprites.zig`.

## Data

`assets/gen/*.bin` are generated by `tools/build_tracks.py` from
`cart/src/tracks/*.track` and committed; formats in `PLAN.md`. They reach
the cart through the `assets` module that `build.zig` generates (one
`@embedFile` per file; nothing is decoded at comptime, the Mac OOM rule).
Rebuild after editing a `.track` file or the painters:

```sh
python3 tools/build_tracks.py        # from this directory
```

## Gates

- `zig build -Dcart=snouty-zero`, `zig build test`, `zig build check-float`
  (from the repository root) all pass.
- The cart is integer-only: no floats in simulation or rendering.
- badge-bench before and after each milestone, worst `busy ms` recorded
  in `PLAN.md`.
- No neopixel code; sound off at boot with a toggle (`docs/SOUND.md`).
