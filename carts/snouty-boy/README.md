# Snouty Boy

A Game Boy emulator cart for the SYCL Badge V2, written in Zig for
Antithesis. One homebrew ROM is baked in; hold Select for the emulator menu
and scrub time backwards and forwards through deterministic replay.

- `SPEC.md`: design, architecture, milestones, decisions.
- `PLAN.md`: current milestone contract.
- `docs/RUNNING.md`: build, test, simulate, flash.

Companion carts: [snouty-badge](https://github.com/antithesishq/snouty-badge),
[snouty-bugs](https://github.com/antithesishq/snouty-bugs).
