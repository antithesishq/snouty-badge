# snouty-badge

Antithesis's animated Snouty cart for the SYCL Badge V2. See `CLAUDE.md` for the
hardware, API, and build notes.

Snouty runs infinitely, and jumps with button input. 

The panel shows "Adrian Hatch" by default. Set a different name at build
time, at most 14 characters:

```
zig build -Dname="Carl Sverre"
```
